使用说明：

1. 启动游戏（npm start 或直接打开index.html）
2. 在菜单页面可以看到当前排行榜
3. 开始游戏并获得分数
4. 游戏结束后：
   - 如果分数进入前3名，会弹出昵称输入框
   - 输入昵称（2-12字符）按Enter确认
   - 可以在排行榜中看到新记录
5. 刷新页面后，排行榜数据依然保留

技术细节：

存储结构：
{
  "leaderboard": [
    {"score": 200, "nickname": "Bob", "timestamp": 1234567890},
    {"score": 150, "nickname": "Alice", "timestamp": 1234567891},
    {"score": 100, "nickname": "Charlie", "timestamp": 1234567892}
  ]
}

API接口：

- LeaderboardManager.submitScore(score, nickname)
- LeaderboardManager.getLeaderboard()
- LeaderboardManager.isHighScore(score)
- LeaderboardUI.checkHighScore(score)
- LeaderboardUI.onGameOver(score)
- LeaderboardUI.handleKeyInput(key)
- GameState.checkLeaderboardScore(score)
- GameState.submitToLeaderboard(score, nickname)
- GameState.getLeaderboard()
